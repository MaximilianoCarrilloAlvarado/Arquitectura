# Administrar empleados

## Objetivo principal

Ofrecer una pantalla web para consultar y mantener los registros de empleados. Cada registro contiene un ID generado por la base de datos, nombre, edad y salario. Los cambios se guardan en la base de datos y se pueden consultar al volver a abrir la aplicación.

## Funcionalidades del módulo

1. [Consulta de empleados](Consulta-de-empleados.md): listado, paginación y consulta por ID en la API.
2. [Registro de empleados](Registro-de-empleados.md): alta de un registro con validación de datos y asignación automática de ID.
3. [Edición de empleados](Edicion-de-empleados.md): actualización de los datos de un registro sin cambiar su ID.
4. [Eliminación de empleados](Eliminacion-de-empleados.md): borrado individual y múltiple con confirmación.

Estas son áreas funcionales del mismo módulo; comparten pantalla, API y base de datos. No corresponden a aplicaciones ni a paquetes Java independientes.
